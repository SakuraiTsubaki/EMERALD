## 2. 출처 등급

이번 단계는 다음 두 최신 한국어 데이터 계열을 독립적으로 대조했다.

1. PKHeX 한국어 기술명 리소스
2. PokéAPI 한국어 `move_names` 테이블

기술 ID 1–251은 두 자료에서 251개 전부 일치했다. 다만 두 자료 모두 포켓몬코리아가 직접 발행한 웹 문서가 아니라 정식 게임의 현지화 데이터를 반영하는 외부 데이터 미러다. 따라서 각 행의 검증 상태는 `CURRENT_LOCALIZATION_DATA_CONSENSUS`로 기록했으며 `DIRECT_OFFICIAL_SOURCE_VERIFIED`로 과장하지 않았다.

이 목록은 구현 기준 후보로 사용할 수 있지만, 포켓몬코리아·한국닌텐도 등 1차 자료에서 개별 기술명이 발견되면 해당 행에 직접 출처를 추가하고 검증 등급을 올린다.

전체 대응은 `move_name_change_list.csv`에 ID·주소·바이트 증감과 함께 기록했다.

## 5. 구현 영향

Bank `0x6C`의 기술명은 포켓몬명처럼 10바이트 고정 슬롯이 아니라 종료 코드가 붙는 가변 길이 연속 표다.

- 기존 251레코드: 2,199바이트
- 현재 명칭 251레코드: 2,170바이트
- 총 29바이트 감소
- 가장 긴 새 기술명: 14바이트
- 모든 글자: 기존 GS Korean 문자표로 인코딩 가능

따라서 전체 표 공간은 늘릴 필요가 없다. 실제 삽입 단계에서는 첫 변경 이후 뒤따르는 문자열 주소가 이동하므로, 기술명 접근 방식이 순차 검색인지 포인터 참조인지 호출 루틴을 재확인한 뒤 표 전체를 재조립한다. UI에서는 개별 최장 14바이트 이름의 전투·상태·기술 목록 표시 폭을 실기 화면으로 검사해야 한다.

## 6. Phase 4 설명 연결

`move_name_current_comparison.csv/.json`의 각 행에는 다음이 함께 들어 있다.

- 기술 ID와 GS Korean 원명
- 현재 한국어 후보명
- 변경 분류 및 출처 상태
- 기존·새 인코딩 길이와 바이트 증감
- Bank `0x6C` 원명 주소
- Bank `0x6D`의 기존 한국어 기술 설명과 주소

명칭이 현대화되어도 기술 효과는 Generation II 원작의 실제 동작을 기준으로 유지한다. 후대의 위력·명중률·부가 효과를 설명에 역수입하지 않는다.
