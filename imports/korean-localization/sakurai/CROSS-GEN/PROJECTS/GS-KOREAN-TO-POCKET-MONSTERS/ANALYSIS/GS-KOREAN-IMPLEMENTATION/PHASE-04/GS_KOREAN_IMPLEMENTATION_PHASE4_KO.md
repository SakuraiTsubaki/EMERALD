# GS Korean 한국어 구현 분석 Phase 4

## 목적

한국 정식판 『포켓몬스터 금』·『포켓몬스터 은』의 기술 설명 Bank `0x6D`를 실제 ROM에서 전수 추출하고, 기술명 Bank `0x6C`와 ID로 연결한다. 기존 한국판의 명칭과 설명은 구현 원문 열로 보존하며 최신 공식 한국어 명칭 또는 최종 번역으로 간주하지 않는다.

## 확정된 Bank 6D 구조

| 영역 | Bank 오프셋 | CPU 주소 | 크기/개수 |
| --- | --- | --- | ---: |
| 전체 포인터 표 | `0x0000–0x01FF` | `0x4000–0x41FF` | 256 × 2바이트 |
| 공통 미사용 설명 | `0x0200–0x0201` | `0x4200–0x4201` | `E6 50` = `<?>@` |
| 실제 기술 설명 | `0x0202–0x32D2` | `0x4202–0x72D2` | 251개 |
| 뒤쪽 0 채움 영역 | `0x32D3–0x3FFF` | `0x72D3–0x7FFF` | 3,373바이트 |

포인터 표의 1–251번 슬롯은 각각 기술 ID 1–251의 설명을 가리킨다. 252–256번의 다섯 슬롯은 모두 `0x4200`의 공통 미사용 문자열을 가리킨다. 첫 실제 설명은 `0x4202`에서 시작한다.

## 문자열 형식

각 설명은 가변 길이 문자열이며 `0x50`으로 끝난다. 251개 설명 모두 화면 전환 제어 코드 `<NEXT>`(`0x59`)를 정확히 한 번 포함한다.

```text
설명 첫 화면 + 0x59 + 설명 다음 화면 + 0x50
```

레코드 길이는 종료 코드 포함 최소 28바이트, 최대 67바이트, 평균 약 49.79바이트다.

## 출력 루틴

기술 설명 출력 루틴은 Bank `0x0B`, CPU `0x4952`, 파일 오프셋 `0x02C952`에서 확인했다. 루틴은 현재 기술 ID에서 1을 뺀 뒤 Bank `0x6D:4000`의 16비트 포인터를 읽고, 같은 Bank의 대상 문자열을 출력한다.

## Gold/Silver 비교

- Bank `0x6D` 전체 SHA-256 동일
- 256개 포인터 표 동일
- 공통 미사용 설명 동일
- 251개 기술 설명과 원시 바이트 동일
- Bank `0x6C`의 기술명과 ID 순서로 1:1 연결됨

따라서 기술명·기술 설명의 구현 자료는 Gold/Silver 공통 원장으로 관리할 수 있다. 다만 최종 명칭과 문장은 최신 공식 자료 및 대상 원문에 따라 별도 검토한다.

## 무손실 검증

- 기술 설명 251개 디코드→인코드 일치
- 미정의 문자 코드 0개
- 실제 포인터 251개를 설명 시작 주소에서 재계산하여 원본과 일치
- 미사용 포인터 5개가 모두 `0x4200`임을 확인
- Bank `0x6D` 재구성 결과가 원본과 일치
- Gold/Silver 전체 ROM의 메모리 내 재구성 SHA-1이 각각 원본과 일치
- ROM 출력 파일은 생성하지 않음

## 생성한 작업 자료

- `move_descriptions_ko.csv/json`: 251개 기술명·설명·주소·원시 바이트
- `move_description_pointer_table.csv/json`: 실제 251칸과 미사용 5칸을 포함한 256개 포인터
- `official_move_name_description_master.csv/json`: 최신 공식 명칭과 최종 설명을 입력할 251행 원장
- `phase4_summary.json`: 해시·범위·검증 결과
- `analysis_pipeline/gs_korean_move_descriptions_scan.py`: 재현 가능한 추출·재조립 검사 도구

## 번역 단계 주의사항

`막치기`, `고양이돈받기`, `김밥말이`, `잼잼펀치` 같은 문자열은 GS Korean에서 실제 추출된 과거 명칭이다. 최신 공식 명칭 여부는 아직 확정하지 않았으므로 공식 명칭 원장의 빈 열과 검증 상태 `PENDING_OFFICIAL_CROSSCHECK`를 유지한다. 기술 효과를 현대 세대의 효과 설명으로 바꾸지 않고, Generation II의 실제 효과와 대상 일본어·영어 원문을 기준으로 최종 문장을 작성해야 한다.

구조 대조 자료는 `pret/pokegold`의 `data/moves/descriptions.asm`과 `engine/pokemon/print_move_description.asm`이다. 실제 주소·바이트·한국어 문자열 판정의 최종 근거는 한국 정식판 Gold/Silver ROM이다.
