# GS Korean 문자표·Bank 6C UTF-8 추출 — 2단계

## 완료 결과

한국 정식판 금·은의 `78–7A` 글꼴 슬롯과 문자 코드를 대응시키고, `6C` 뱅크의 명칭 830개를 UTF-8로 완전 추출했다. 추출한 문자열을 다시 인코딩해 Bank 6C와 ROM 전체를 재구성했으며 금·은 모두 원본과 바이트 단위로 일치했다.

| 항목 | 결과 |
| --- | ---: |
| 한글 완성형 코드 | 2,353개 |
| `0B` 보조 문자 코드 | 66개 |
| 전체 2바이트 코드 | 2,419개 |
| 정의된 1바이트 값 | 242개 |
| 실제 단일 문자 매핑 | 177개 |
| 제어·치환 토큰 | 65개 |
| Bank 6C 명칭 | 830개 |
| 정의되지 않은 코드 | 0개 |
| 회귀 검증 | 9/9 통과 |

## Bank 6C 추출 범위

| 분류 | 레코드 | 저장 방식 |
| --- | ---: | --- |
| 도구명 | 256 | `50` 종료 가변 길이 |
| 트레이너 분류명 | 67 | `50` 종료 가변 길이 |
| 포켓몬 이름 슬롯 | 256 | 슬롯당 10바이트 |
| 기술명 | 251 | `50` 종료 가변 길이 |
| 합계 | 830 | — |

10바이트 포켓몬 이름 슬롯 가운데 6개는 5개의 2바이트 글자를 사용해 슬롯을 전부 채우므로 내부 종료 코드가 없다. 추출기와 재삽입기는 이 실제 저장 규칙을 처리한다.

## 디코딩 표본

- 도구: `마스터볼`, `하이퍼볼`, `반짝가루`, `수퍼볼`, `몬스터볼`
- 포켓몬: `이상해씨`, `이상해풀`, `이상해꽃`, `파이리`, `리자드`, `리자몽`
- 기술: `막치기`, `태권당수`, `연속 뺨치기`, `연속펀치`, `메가톤펀치`, `고양이돈받기`

여기 적힌 명칭은 기존 GS Korean 문자열의 정확한 추출 결과이지 최신 공식 명칭으로 확정한 결과가 아니다. 예를 들어 `수퍼볼`, `고양이돈받기` 같은 표현은 다음 명칭 대조 단계에서 현재 공식 명칭과 비교한다.

원본 ROM 파일에는 쓰기 작업을 하지 않았다. 재구성 검증은 메모리에서 수행했으며 수정 ROM을 산출물에 포함하지 않는다.

## 문자표 검증 방법

1. ROM `78–7A`의 8×8 글리프 타일에서 비어 있지 않은 `01–0A` 슬롯 2,353개를 직접 산출했다.
2. 각 슬롯의 Unicode 음절을 기존 한국어 명칭과 대조했다.
3. 공개 디스어셈블리의 문자표를 보조 교차 검증 자료로 사용했다.
4. 830개 문자열에서 정의되지 않은 코드가 0개인지 확인했다.
5. UTF-8 디코딩 → 원래 코드 재인코딩 후 Bank 6C 및 전체 ROM 해시를 비교했다.

교차 검증 자료: [Narishma-gb/pokegold-kr charmap](https://github.com/Narishma-gb/pokegold-kr/tree/master/constants/charmap)

## 공식 명칭 대조 원장

`official_name_comparison_master.csv/json`에 830개 행을 생성했다. 현재 단계에서는 `original_gs_korean`만 채웠으며 다음 항목은 공식 자료 확인 전까지 비워 두었다.

- 최신 공식 한국어 명칭
- 최종 적용 명칭
- 공식 출처
- 검증 상태
- 변경 이유

확인되지 않은 항목을 공식 명칭으로 단정하지 않기 위해 모든 행의 초기 상태는 `PENDING_OFFICIAL_CROSSCHECK`다.
