# GS Korean 한국어 구현 분석 Phase 5

## 목적

한국 정식판 『포켓몬스터 금』·『포켓몬스터 은』의 도구 설명 Bank `0x6E`를 실제 ROM에서 전수 추출한다. 256개 도구명 슬롯을 설명 포인터와 연결하고, 공유 문자열·미사용 슬롯·기술머신/비전머신 출력 분기를 보존한 공식 명칭 대조 원장을 만든다.

## 확정된 Bank 6E 구조

| 영역 | Bank 오프셋 | CPU 주소 | 크기/개수 |
| --- | --- | --- | ---: |
| 포인터 표 | `0x0000–0x01FF` | `0x4000–0x41FF` | 256 × 2바이트 |
| 설명 문자열 풀 | `0x0200–0x1A6F` | `0x4200–0x5A6F` | 고유 문자열 198개 |
| 뒤쪽 0 채움 영역 | `0x1A70–0x3FFF` | `0x5A70–0x7FFF` | 9,616바이트 |

256개 포인터는 모두 같은 Bank의 유효한 문자열 시작 주소를 가리킨다. 고유 설명은 198개이며, 중복 참조를 제외한 공유 포인터 초과분은 58개다. 문자열 풀은 `0x4200`부터 `0x5A70` 직전까지 빈틈 없이 연속 배치되어 있다.

## 슬롯과 도구 ID

Bank `0x6C`의 256개 도구명 레코드와 Bank `0x6E`의 포인터 슬롯은 같은 순서를 사용한다.

```text
슬롯 0   → 도구 ID 0x01 마스터볼
슬롯 1   → 도구 ID 0x02 하이퍼볼
...
슬롯 254 → 도구 ID 0xFF
슬롯 255 → ID 0x00에서 1을 뺀 경우의 언더플로 슬롯
```

과거 한국판 이름이 `?` 또는 `<?>`인 슬롯은 35개다. 이는 최신 공식 명칭이 없다는 판정이 아니라 내부 슬롯·미사용 ID 여부를 후속 검증해야 한다는 뜻이다.

## 기술머신·비전머신 분기

도구 설명 출력 루틴은 Bank `0x0B`, CPU `0x4000`, 파일 오프셋 `0x02C000`에 있다.

- 현재 도구 ID가 `0xBF` 미만이면 Bank `0x6E` 포인터 표를 사용한다.
- `0xBF` 이상이면 도구 ID를 기술 ID로 변환한 뒤 Bank `0x6D`의 기술 설명 출력 루틴으로 넘긴다.
- 따라서 기술머신/비전머신 구간에서 Bank `0x6E`의 `?` 설명이 반복되는 것은 정상적인 미사용 자리다.
- 비교 명령 자체는 `0xBF–0xFF`의 65개 ID를 기술 설명 경로로 보낸다. 실제 사용 가능한 TM/HM과 내부 빈 ID의 구분은 별도 슬롯 분류에서 확정한다.

## 문자열 현황

| 항목 | 결과 |
| --- | ---: |
| 전체 포인터 슬롯 | 256 |
| 고유 설명 문자열 | 198 |

## Gold/Silver 비교 및 무손실 검증

- Gold/Silver Bank `0x6E` 전체 SHA-256 동일
- 256개 포인터와 198개 고유 설명 동일
- Bank `0x6C` 도구명 연결 결과 동일
- 모든 고유 문자열 디코드→인코드 일치
- 모든 포인터가 실제 문자열 경계와 일치
- 문자열 풀을 주소 순서로 재조립한 결과가 원본과 일치
- Bank `0x6E` 및 전체 ROM 메모리 내 재구성 결과가 각각 원본과 일치
- ROM 출력 파일은 생성하지 않음

## 생성한 작업 자료

- `item_description_slots_ko.csv/json`: 256개 슬롯별 도구명·ID·설명·출력 경로
- `item_description_pool_ko.csv/json`: 198개 고유 설명 문자열과 참조 슬롯
- `item_description_pointer_table.csv/json`: 256개 포인터와 대상 주소
- `official_item_name_description_master.csv/json`: 최신 공식 명칭·최종 설명·출처를 기록할 256행 원장
- `phase5_summary.json`: 해시·범위·집계·검증 결과
- `analysis_pipeline/gs_korean_item_descriptions_scan.py`: 재현 가능한 추출·재조립 검사 도구

## 번역 단계 주의사항

추출된 `수퍼볼`, `달맞이 돌`, `동굴탈출 로프`, `벌레회피스프레이` 등의 표기는 GS Korean 구현 원문이다. 최신 공식 한국어 명칭이나 최종 문장으로 확정하지 않았다. 후속 대조에서는 최신 공식 명칭, Generation II의 실제 기능, 대상 일본어·영어 원문을 각각 분리해 기록한다. 최신 세대에서 효과가 변경된 도구는 현대 설명을 그대로 역수입하지 않는다.

구조 대조 자료는 `pret/pokegold`의 `engine/items/print_item_description.asm`이다. 실제 주소·포인터·한국어 문자열 판정의 최종 근거는 한국 정식판 Gold/Silver ROM이다.
