# GS Korean 한국어 구현 분석 Phase 3

## 목적

한국 정식판 『포켓몬스터 금』·『포켓몬스터 은』의 도감 항목 저장 구조를 실제 ROM에서 추출하고, Gold/Silver의 설명 차이를 보존한 UTF-8 작업 자료와 재현 가능한 검증 도구를 만든다. 이 단계는 기존 한국어 문장을 번역 기준으로 채택하는 작업이 아니라 구현 구조를 확정하는 작업이다.

## 확정된 구조

도감 번호 1–128은 Bank `0x68`, 129–251은 Bank `0x69`에 저장된다. 각 항목의 직렬화 형식은 다음과 같다.

```text
분류명(가변 길이) + 0x50 + 키(1바이트, dm) + 몸무게(2바이트 LE, hg)
+ 도감 설명(가변 길이) + 0x50
```

- 모든 251개 설명에는 `<NEXT>`(`0x59`)가 정확히 2개 존재한다.
- Bank 11의 `0x42FF`(파일 `0x0442FF`)에 251개의 16비트 포인터가 있다.
- 포인터는 항목이 속한 Bank 안의 CPU 주소 `0x4000–0x7FFF`를 가리킨다.
- Bank 선택 루틴은 Bank 11의 `0x42E8`(파일 `0x0442E8`)에 있다.
- 루틴은 `(도감번호 - 1)`의 최상위 비트로 `0x68` 또는 `0x69`를 선택하고, 같은 인덱스의 16비트 포인터를 읽는다.

## Gold/Silver 비교

| 항목 | 결과 |
| --- | ---: |
| 비교한 도감 항목 | 251 |
| 동일한 분류명 | 251 |
| 동일한 키 | 251 |
| 동일한 몸무게 | 251 |
| 동일한 설명 | 0 |
| 서로 다른 설명 | 251 |
| 동일한 포인터 표 | 아니요 |

Gold와 Silver는 분류명·키·몸무게가 모두 같지만, 도감 설명은 251개 전부 다르다. 문장 길이가 달라 각 항목의 시작 주소도 달라지므로 포인터 표 역시 버전별로 별도 관리해야 한다.

## Bank 사용량

| 버전 | Bank | 도감 번호 | 사용 바이트 | 뒤쪽 0 채움 여유 |
| --- | --- | --- | ---: | ---: |
| Gold | `0x68` | 1–128 | 10,817 | 5,567 |
| Gold | `0x69` | 129–251 | 10,375 | 6,009 |
| Silver | `0x68` | 1–128 | 10,788 | 5,596 |
| Silver | `0x69` | 129–251 | 10,478 | 5,906 |

현재 ROM에는 두 Bank 모두 연속된 도감 데이터 뒤에 0으로 채워진 여유 공간이 있다. 이 수치는 새 번역 배치 후보를 계산할 때 참고할 수 있지만, 다른 참조나 확장 계획을 확인하기 전까지 자유 공간으로 확정하지 않는다.

## 무손실 검증

- Gold 251개 항목 디코드→인코드 일치
- Silver 251개 항목 디코드→인코드 일치
- Gold/Silver의 251개 포인터 표 재계산 결과가 원본과 일치
- Bank 68·69의 파싱 종료점이 각 Bank의 마지막 비영(非零) 바이트 다음 위치와 일치
- 나머지 Bank 뒤쪽이 모두 `0x00`임을 확인
- 메모리 안에서 재구성한 전체 ROM의 SHA-1이 입력 ROM과 일치
- ROM 출력 파일은 생성하지 않음

## 출력 파일

- `pokedex_entries_ko.csv/json`: Gold/Silver 502개 원문 항목, 주소, 원시 바이트, 분류명, 키, 몸무게, 설명
- `pokedex_pointer_table.csv/json`: 버전별 251개 포인터와 실제 대상 주소
- `pokedex_gold_silver_diff.csv/json`: 251개 항목의 버전 차이 병렬 비교
- `phase3_summary.json`: 해시, Bank 사용량, 검증 결과
- `analysis_pipeline/gs_korean_pokedex_scan.py`: 같은 결과를 ROM에서 다시 생성하는 분석 도구

## 해석상 주의

추출된 한국어에는 과거 맞춤법·띄어쓰기·명칭이 그대로 포함되어 있다. 이는 공식 한국어 구현 원문을 보존한 분석 열이며, 현대 한국어 최종 번역 열이 아니다. 후속 단계에서는 원본 일본어·영어 도감 문장을 각각 독립적으로 추출하고, 최신 공식 한국어 명칭과 현재 맞춤법을 적용한 별도 번역 열을 만든다.

구조 대조 자료: `pret/pokegold`의 `engine/pokedex/pokedex_2.asm`, `data/pokemon/dex_entry_pointers.asm`, `data/pokemon/dex_entries_gold.asm`, `data/pokemon/dex_entries_silver.asm`. 구조 판정과 주소·내용 검증의 최종 근거는 이 프로젝트가 보유한 실제 한국 정식판 ROM이다.
